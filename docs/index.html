Each word is a 2048-bit hypervector: a majority bundle of its character bigrams and trigrams, letter order encoded by permutation. A word that is not in the vocabulary is compared with every stored form by Hamming distance; the closest ones are re-ranked by edit distance, and the best is accepted only if it is one edit away (two for long words) and the change does not add or drop a prefix.

Use it

One script tag
<script src="https://cdn.jsdelivr.net/gh/ml-circuits-research/vsa-ro-translate@v0.2.0/dist/vsa-ro-translate.min.js"></script>
<script>
  VSARoTranslate.translate('Șterge toate săgețile roșii');
  // → "Delete all the red arrows"
</script>
Your vocabulary and settings
const { create, dictionaries } = VSARoTranslate;
const t = create({
  dictionaries: [dictionaries.ro, dictionaries.en, {
    lang: 'ro', name: 'acme',
    words: { tichet: { en: 'ticket', plural: 'tichete' },
             'tichet de suport': 'support ticket' },
  }],
  chrome: 'fallback',   // 'never' | 'fallback' | 'prefer'
  strict: false,
});
const r = await t.translateAsync('Închide tichetul de suport');
r.text; r.ok; r.errors; r.engine;
Spell check
const s = t.spellcheck('Seteaza opacitaea stratului seletat');
s.text;     // "Seteaza opacitatea stratului selectat"
s.errors;   // words not in the vocabulary, with suggestions
s.tokens;   // per word: ok | corrected | unknown | name
Another language
<script src=".../dist/dictionaries/fr.js"></script>
const f = create({ dictionaries: [dictionaries.fr, dictionaries.en] });
f.translate('Ne supprime pas la légende').text;
// → "Don't delete the legend"

How it works

The VSA part

  • Vocabulary memory. Every word form of every dictionary (inflections are generated for Romanian) becomes a 2048-bit hypervector, built by bit-sliced majority bundling in a few hundred milliseconds, lazily.
  • Spelling. Hamming search over the whole memory, then a re-rank by edit distance, length and language, as in vsa-spell. Safety rules keep unknown words from being "corrected" into different ones.
  • Language. Each sentence's language is the vote of its words that exist in only one dictionary, so Romanian with English terms stays Romanian, and English sentences are only spell checked.
  • Word sense. Ambiguous words pick the sense whose bundled context vector matches the sentence.

What it is not

  • Word order comes from rules: a full Romanian set, and generic Romance rules (adjective after noun, articles, "de", negation) for other languages.
  • It is a closed-vocabulary tool. Words it does not know are errors; with the Chrome setting they can go to a neural translator instead.
  • Names and quoted labels are kept as written, because an agent has to find them on the canvas.
