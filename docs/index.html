Romanian commands for diagram, editing, animation and enterprise tools, translated to plain English in your browser. Under a millisecond per command, about 110 KB of code, no model to download. Telegraphic English, built to be understood by people and by agents.

Each word is a 2048-bit hypervector: a majority bundle of its character bigrams and trigrams, with letter order encoded by permutation. A word the lexicon does not contain verbatim is matched to the nearest stored form by Hamming distance. Pick any word above to see its vector and its nearest neighbour.

How well it works

Measured on 160 commands written by independent agents, never used to build the lexicon. A slot is something an agent needs to act correctly: the action, the object, a value, a unit, a direction. chrF is the standard character-level overlap with a human reference translation (sacreBLEU settings).

Knowing when it doesn't know

A translation is confident when every content word was found (exactly or by a strong VSA match). Route the rest to a neural translator: that is the hybrid the comparison below measures.

Robustness

Compare with Chrome, in this browser

Desktop Chrome 138+ and Edge ship an on-device translator (the Translator API). This runs both systems on the same 160 commands and scores them the same way. Chrome downloads its Romanian model the first time.

  'https://cdn.jsdelivr.net/gh/ml-circuits-research/vsa-ro-translate@v0.1.1/dist/vsa-ro-translate.mjs';

const r = translateDetailed('Exportă diagrama ca PDF');

Hybrid: VSA first, Chrome when unsure
async function toEnglish(ro) {
  const r = VSARoTranslate.translateDetailed(ro);
  if (r.stats.confident || !('Translator' in self)) return r.text;
  const t = await Translator.create({ sourceLanguage: 'ro', targetLanguage: 'en' }); // needs a user gesture the first time
  return t.translate(ro);
}

How it works

The VSA part

  • Lexical memory. About 5,500 Romanian word forms (generated from ~800 lemmas with their inflections, plus ~250 function words and ~200 phrases) each get a 2048-bit hypervector. Exact forms are found directly; anything else is cleaned up to the nearest stored vector, which absorbs missing diacritics, typos and unseen inflections.
  • Word sense. Ambiguous words (rulează: run or play, anulează: undo or cancel) pick the sense whose bundled context vector best matches the sentence.
  • Bit-sliced majority bundling builds the whole memory in about 0.25 s, lazily, on the first unknown word.

What it is not

  • Word order and grammar (noun–adjective order, genitives, clitics like mută-l, prepositions, questions) come from a small rule layer, not from VSA.
  • It is a closed-vocabulary tool. Unknown words pass through in Romanian and the result is marked not confident.
  • Only Romanian → English for now. Other Indo-European sources need their own lexicon and a few order rules.
  • Names and quoted labels (nodul „Aprobare”) are kept as written, because an agent has to find them on the canvas.
